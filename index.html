雲端同步

讓手機、平板、筆電等多個裝置的資料自動保持一致
🔧 設定步驟（只需在每台裝置各設定一次）
  1. 前往 console.firebase.google.com，用 Google 帳號登入，建立一個新專案（免費方案即可，可以不用開 Google Analytics）
  2. 建立完成、進入專案畫面後，點左側選單「建構 Build」→「Realtime Database」→「建立資料庫 Create Database」，地區任選，安全性規則先選「測試模式 Test mode」→ 啟用
  3. 重要，容易漏掉：左側選單「建構 Build」→「Authentication」→「開始使用 Get started」→上方分頁選「Sign-in method」→ 找到清單裡的「匿名 Anonymous」→ 點進去打開「啟用 Enable」開關 → 儲存。（這一步沒做，等一下按「連線」會失敗）
  4. 點左上角齒輪 ⚙️ →「專案設定 Project settings」→ 頁面下方「你的應用程式 Your apps」找不到應用程式的話，點 </>（網頁）圖示新增一個，取個名字（例如 web）即可，不需要勾選 Firebase Hosting，一路「下一步」到完成
  5. 應用程式建立後，畫面會顯示一段 const firebaseConfig = {'{'}...{'}'} 程式碼，整段選取複製；之後想再找這段設定，可以到「專案設定」一般頁籤下方「你的應用程式」，點你的網頁應用程式，選「設定 Config」
  6. 重要，容易漏掉：這段程式碼通常不會自動包含 databaseURL 這一行。請另外到左側選單「Realtime Database」頁面，畫面最上方會顯示一個網址（例如 https://你的專案id-default-rtdb.地區.firebasedatabase.app），複製它，手動貼到 firebaseConfig 裡加一行 databaseURL: "貼在這裡",（前後留意要有逗號跟雙引號）
  7. 回到這裡，把整段（含手動加上 databaseURL 之後）貼到下方「Firebase 設定」欄位
  8. 自訂一組「同步代碼」（例如店名縮寫＋隨機數字，不要用太簡單的字），所有裝置都要輸入完全相同的代碼才能同步到一起
  9. 按「連線並開始同步」。之後回到 Realtime Database 的「規則 Rules」分頁，建議改成下方提供的安全規則，避免任何人都能讀寫你的資料
🔒 建議的安全規則（貼到 Realtime Database →「規則」分頁）
{
  "rules": {
    "syncData": {
      "$syncCode": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
設定這個規則後，只有通過驗證（本工具會自動使用「匿名登入」）的連線可以讀寫，一般人不會知道你的同步代碼，等於多一層保護。由於資料是透過網址中的「同步代碼」區分不同店家，代碼愈長、愈不容易被猜到愈安全。
